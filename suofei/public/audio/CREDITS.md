# Audio credits

All three background tracks are distributed under CC0 and are bundled locally so the game can play them without third-party network requests.

- `jazz-table.ogg` — “Jazz” by Spring Spring: https://opengameart.org/content/jazz-1
- `lofi-table.ogg` — “Lofi Hip Hop Loop” by omfgdude / OMF-Games: https://opengameart.org/content/lofi-hip-hop-loop
- `electronic-jazz.mp3` — “Electronic Jazz (Chromatic)” by Pro Sensory / Alex McCulloch: https://opengameart.org/content/electronic-jazz-chromatic

Interface sound effects are synthesized at runtime with the Web Audio API and do not use external samples.
