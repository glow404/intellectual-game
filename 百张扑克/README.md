# 十手牌 · Poker Ten

一款本地单机扑克牌策略游戏。玩家与电脑各自使用一副去掉大小王的52张牌，留下2张，将其余50张组成十种固定牌型，再通过十轮暗选对战决出胜负。

## 运行

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址即可。游戏进度和按难度统计的战绩保存在当前浏览器的 `localStorage` 中。

## 规则摘要

- 十种牌型为：皇家同花顺、同花顺、四条、葫芦、同花、顺子、三条、两对、一对、散牌。
- 牌型按标准德州扑克顺序比较；同类牌完全同点时，逐张按黑桃 > 红心 > 方片 > 梅花破平。
- 每轮双方暗选一组尚未使用的牌并同时揭晓。赢家获得自己五张牌中的最高牌面点数，A为14分；完全相同则双方均得0分。
- A2345在比较时是5高顺子，但获胜计分仍为14分。
